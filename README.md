# 마감한끼

모바일 중심의 정적 웹 프로토타입입니다. `dist/`를 정적 서버로 제공하며 Sites 배포 설정은 `.openai/hosting.json`에 있습니다.

## 화면과 흐름

- 손님용 하단 탭: 피드, 지도, 내 주문. 상단 사장 ver 버튼으로 사장님용 등록, 주문, 관리 탭 전환
- 모든 화면 상단의 설정 버튼에서 글자 크기 조절과 한국어 음성 안내 제공
- 피드: 같은 가게의 메뉴를 카드 하나로 묶고 사진을 한 번에 최대 3장 표시. 상품이 더 많으면 좌우 스와이프 또는 버튼으로 넘겨 봄. 가게 카드는 가까운 순이며 각 카드에 거리를 표시. 최근 재고 등록 매장 목록은 왼쪽부터 최신순 유지. 위치 권한을 쓰지 않으면 성수동 예시 위치 기준 거리 표시. 서울 전체·지역별 보기, 상품별 좋아요와 장바구니 제공
- 골목 세트 버튼: AI 맞춤 음식 조합 기능을 안내하고, 현재는 인원·예산·커피 제외 문장을 규칙으로 분석해 기준 위치 3km 이내 재고에서 조합을 추천. 1km 이내 가게 우선, 조합 유지 시 개별 할인가 합계에서 골목 응원 할인 적용. 데이터 처리 단계는 [PIPELINE.md](PIPELINE.md)에 정리
- 데모 주문: 상품을 담고 확정하면 최근접 픽업 순서, 지도 위 방문 동선, 가게 위치, 예상 픽업 시간 안내
- 지도: 카카오맵과 3km 반경, 서울 전역 샘플 가게 마커, 메뉴 검색, 가게 정보 자리 표시
- 내 주문: 진행 중인 주문과 픽업 완료 내역에 상품별 개당 가격·수량별 금액·주문 총 가격 표시, 좋아요 남긴 가게, 추후 제공할 리뷰 버튼
- 등록: 성수동 오후의 빵집에 사진 촬영/업로드, 음성 인식 또는 텍스트 입력, 상품명·가격·재고·마감시간 초안, 확인 후 등록
- 주문: 오후의 빵집에 들어온 주문을 번호, 상품별 개당 가격·수량별 금액, 가게 총 가격과 도착 예상 시간으로 확인하고 주문 수락 → 준비 완료 → 픽업 완료 순서로 상태 변경. 픽업 완료 주문은 완료 내역으로 이동. 처음에는 예시 주문 2건 표시
- 관리: 오후의 빵집 메뉴 7개의 이름·가격·수량·마감시간 수정

## 현재 데이터와 연동 범위

화면 전환, 메뉴 카드, 버튼, 주문 모달에 짧은 애니메이션을 적용하고 모바일·데스크톱 폭에 따라 지도 높이와 사장님 주문 카드 배치를 조정합니다. 운영체제의 동작 줄이기 설정을 따릅니다.

서울 18개 지역의 가상 가게 20곳에 재고가 있는 샘플 메뉴 총 88개가 등록되어 있습니다. 이 중 10곳을 한식 3곳, 양식 3곳, 중식 2곳, 일식 2곳으로 구성하고 각 분야에 메뉴 6개씩 추가했습니다. 성수동 오후의 빵집에는 7개 메뉴가 있습니다. 모든 메뉴의 정가에서 메뉴별로 20~30%를 할인한 가격을 표시합니다. 기본 피드는 성수동 예시 위치에서 3km 이내를 보여 주며 지역 선택에서 서울 전체나 다른 동네를 둘러볼 수 있습니다. 위치 권한을 사용하면 실제 현재 위치 기준으로 3km 이내 샘플 가게를 표시합니다. 메뉴, 재고, 좋아요, 주문은 현재 브라우저의 localStorage에만 저장됩니다. 새로운 날짜에는 샘플 메뉴가 갱신됩니다. 실제 가게 데이터, 외부 AI 모델, 서버 재고 동기화, 결제, 실제 주문 전송, 픽업 예약은 연결되지 않았습니다. 추천과 상품 정보 추출은 규칙 기반 데모입니다. 픽업 시간은 준비 10분과 도보 거리로 계산한 예상치입니다.

지도는 카카오맵 Web JavaScript SDK를 사용합니다. 배포 도메인이 카카오디벨로퍼스의 JavaScript SDK 도메인에 등록되어 있어야 합니다. SDK를 불러오지 못하면 안내용 지도가 표시됩니다. 상품 사진은 샘플 이미지이며 식당 카테고리는 생성한 대표 음식 사진을 공유합니다.

픽업 지도는 첫 방문 가게를 중심으로 전체 경로 보기보다 최대 4단계 확대해 시작합니다. 첫 가게와 전체 동선 버튼으로 보기를 전환할 수 있습니다. 출발 위치와 주문 가게를 직선으로 연결한 안내이며 실제 도로 길찾기 경로는 아닙니다. 손님 주문과 사장님 주문 상태는 같은 브라우저에서만 공유되며, 다른 기기와는 동기화되지 않습니다.

## 검증

`node --check dist/v2.js`, `node --check dist/seoul-data.js`, `node --check dist/recommendation-pipeline.js`, `node --test tests/recommendation-pipeline.test.cjs`로 구문과 추천 조건을 확인할 수 있습니다. 추천은 규칙 기반 시연이며, 실제 AI 모델 해석 결과는 `safeIntent` 경계를 통해 연결하도록 분리했습니다.
