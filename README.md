# 한 골목, 한 메뉴

기획안의 기능을 중심으로 만든 인스타그램 스타일 모바일 웹 MVP입니다.

## 구현된 흐름

- 오늘의 골목 피드: 가상 가게 3곳, 오늘 메뉴 9개, 가게·카테고리 필터, 검색, 저장, 좋아요
- 골목 세트: 인원·예산·목적·커피 제외·아이 동반·알레르기 조건, 확인된 가격과 재고로 조합
- 도보 픽업: 가상 좌표의 최근접 순서, 가게별 금액, 큰 글씨 메뉴 확인, 기기 내 수령 표시, 브라우저 음성 안내
- 사장님: 사진 업로드, 입력 문장의 규칙 기반 초안, 큰 글씨 확인 후 게시, 수동 품절 및 수량 등록
- 관리자: 오늘의 메뉴 수, 가게별 등록 현황, 기기 내 세트 구성 횟수
- 반응형 화면, 모바일 하단 탭, 접근성 큰 글씨, 간단한 영어 안내

## 범위

네이티브 iOS/Android 패키지가 아닌 모바일 웹 프로토타입입니다. 데이터는 localStorage에 이 브라우저 기준으로만 저장되며 날짜가 바뀌면 샘플 데이터가 초기화됩니다. 실제 AI, 사진 인식, 공공데이터 API, 실시간 길찾기, 회원가입, 주문·예약·결제, 서버 재고 동기화는 연결하지 않았습니다. 픽업 경로는 가상 좌표의 직선 거리 및 순서 예시입니다. 음식 사진은 Unsplash 샘플 이미지입니다.

## 실행

빌드 및 의존성 설치가 없는 정적 HTML/CSS/JavaScript입니다. `dist/`를 정적 서버에서 제공하세요. `.openai/hosting.json`에 Sites 배포 설정이 있습니다.

## 검증

JavaScript 문법 검사 및 Node VM 기반 기능 검증을 통과했습니다: 19,000원 세트, 인원별 수량, 커피 제외, 알레르기 제외, 예산 부족, 품절 재구성, 전체 품절, 동선 계산, 화면 렌더링. 현재 환경의 브라우저 제어 도구가 제공되지 않아 실제 브라우저 시각·상호작용 검증은 수행하지 못했습니다.
